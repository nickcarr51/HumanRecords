# Human Services Project Bootstrap Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Scaffold the Human Services Next.js/TypeScript project, wire up styled-components and testing, build a placeholder branded home page, seed project conventions, and open a PR so the deploy pipeline (Vercel preview on `develop`) can be verified.

**Architecture:** Single flat Next.js 15 App Router project at the repo root (`src/` layout). styled-components handles all styling via an SSR registry wrapping the root layout. Vitest + React Testing Library cover component tests. No backend integration (Supabase/R2) in this pass.

**Tech Stack:** Next.js 15 (App Router), TypeScript, yarn, styled-components, Vitest, React Testing Library, Node 22.

**Spec:** `docs/superpowers/specs/2026-09-12-project-bootstrap-design.md`

## Global Constraints

- Package manager is yarn only — never use `npm` or `pnpm` commands.
- TypeScript only — no `.js`/`.jsx` source files.
- Styling is styled-components only — no Tailwind, no CSS Modules.
- Node version is 22 (LTS), pinned via `.nvmrc` and `package.json` `engines`.
- Testing this pass is Vitest + React Testing Library only — no Playwright/e2e yet.
- Home page copy is exact: wordmark `HUMAN SERVICES`, subline `By Human Records`, status tag `ACCESS BY INVITATION`.
- Accent color is exactly `#FFD000`.
- Out of scope, do not implement: Supabase client/env wiring, Cloudflare R2, any auth/invite flow, dashboard UI, logo (leave a visual slot only).
- Workflow: commit to the current feature branch, push, and open a PR into `develop` with `gh pr create`. Do **not** merge the PR and do **not** open a `develop` → `main` PR — the user merges manually on GitHub.

  },

- [ ] **Step 3: Create the SSR registry**

Create `src/lib/registry.tsx`:

```tsx
'use client';

import React, { useState } from 'react';
import { useServerInsertedHTML } from 'next/navigation';
import { ServerStyleSheet, StyleSheetManager } from 'styled-components';

export default function StyledComponentsRegistry({
  children,
}: {
  children: React.ReactNode;
}) {
  const [styledComponentsStyleSheet] = useState(() => new ServerStyleSheet());

  useServerInsertedHTML(() => {
    const styles = styledComponentsStyleSheet.getStyleElement();
    styledComponentsStyleSheet.instance.clearTag();
    return <>{styles}</>;
  });

  if (typeof window !== 'undefined') return <>{children}</>;

  return (
    <StyleSheetManager sheet={styledComponentsStyleSheet.instance}>
      {children}
    </StyleSheetManager>
  );
}
```

- [ ] **Step 4: Wire the registry into the root layout**

Edit `src/app/layout.tsx` so it reads:

```tsx

export const metadata: Metadata = {
  title: 'Human Services',
  description: 'Human Records — invite-only music repository',

  children,
}: {
  children: React.ReactNode;
}) {
  return (
    <html lang="en">
      <body>
        <StyledComponentsRegistry>{children}</StyledComponentsRegistry>
      </body>
    </html>
  );
}
```
